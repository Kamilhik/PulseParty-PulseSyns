# PulseParty

Автор: **Kamilhik**. [GitHub](https://github.com/Kamilhik/PulseParty-PulseSyns) · [Релизы](https://github.com/Kamilhik/PulseParty-PulseSyns/releases).

**ИИ использовался:** да, OpenAI Codex. Разработка на официальном WebHost SDK по структуре PulseSync-ExampleAddon. Сторонний аддон, не официальный продукт PulseSync или Яндекса. Изменения текущей версии — в CHANGELOG.md внутри архива.

Компактная комната совместного прослушивания и передача пульта.

0.3.1: добавлена аватарка для лаунчера. Имя из профиля Яндекс Музыки автоматически, синхронизация без всплывающих уведомлений. В «Настройках комнаты» выберите доступ к «Назад»/«Далее»: только владелец или все участники. Кнопки переключают очередь ведущего; передача пульта остаётся отдельной функцией.

Версия 0.3.1 работает с обычным PulseSync через общий HTTPS-сервис. Отдельные программы, companion и замена app.asar участникам не нужны. Адрес сервиса и разрешения сети задаются при сборке; все участники должны использовать сборку для одного сервиса.

Готовая сборка и исходники по умолчанию подключены к общему сервису. Для собственной установки сервера доступны инструкции Cloudflare Workers Free в docs/CLOUDFLARE.md и автодеплой из GitHub в docs/GITHUB-CLOUDFLARE.md исходного проекта.

Текущая готовая сборка настроена на https://pulseparty.pulseparty.workers.dev. Участникам нужен один и тот же сервис; не указывайте localhost.

При входе в комнату общий сервис получает ваше отображаемое имя (при недоступном нике — логин), ID/метаданные трека, позицию и состояние воспроизведения. Аудио, пароли, cookies и токены Яндекса/Discord не передаются. Комнаты хранятся в памяти и могут завершиться при перезапуске сервиса.

Вход — по ссылке/коду в панели «Слушать вместе». Нативные приглашения Discord недоступны через стандартный SDK; обычный статус Discord можно включить в настройках самого PulseSync.

Инструкции, сборки и точные результаты проверок находятся в README.md исходного проекта и docs/VERIFICATION.md.
