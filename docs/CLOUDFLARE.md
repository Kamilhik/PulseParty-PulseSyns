# Бесплатное размещение общего сервиса

Текущий сервис опубликован: https://pulseparty.pulseparty.workers.dev. Публичный `/v1/health` и сценарий трёх HTTP-клиентов проверены; установленный аддон и готовый ZIP настроены на этот адрес. Ниже — воспроизводимые шаги для нового размещения.

Используется **Cloudflare Workers Free + SQLite-backed Durable Objects**. Покупать VPS или домен не требуется: Cloudflare выдаёт `https://<worker>.<account>.workers.dev`. Это шаблон адреса, не работающий сервис PulseParty.

Официальные условия, проверенные 18.11.2026:

- [Workers Free](https://developers.cloudflare.com/workers/platform/limits/): 100 000 запросов в сутки, CPU 10 мс на вызов Worker.
- [Durable Objects Free](https://developers.cloudflare.com/durable-objects/platform/pricing/): 100 000 запросов и 13 000 GB-s в сутки; доступны SQLite-backed классы. На Free превышение лимита приводит к отказу операций; лимиты суток обновляются в 00:00 UTC.
- [Адрес workers.dev](https://developers.cloudflare.com/workers/configuration/routing/workers-dev/): для личных проектов без собственного домена.

Лимит общий для аккаунта и других его приложений. Long polling, публикации и фоновые снимки расходуют запросы; это не безлимитный тариф. Изменения плеера отправляются при следующем цикле синхронизации (по событию, с резервной проверкой 200 мс, плюс сеть), периодическая публикация — раз в 5 секунд. Аудио через сервис не передаётся. Бесплатность относится к сервису комнат, не к подписке Яндекс Музыки или доступу к трекам.

## Публикация владельцем сервиса

Нужен свой аккаунт Cloudflare на Free. Node.js 22.12+ и инструменты сборки нужны только разработчику/владельцу, не участникам комнаты.

```powershell
npm ci
npm run login:cloudflare
```

Войдите в открывшемся браузере и подтвердите доступ Wrangler. Не передавайте пароль или токен в чат. Если аккаунт новый, Cloudflare может попросить подтвердить почту и выбрать поддомен Workers. Не подключайте платный тариф для этой конфигурации.

```powershell
npm run check:cloudflare
npm run deploy:cloudflare
```

`wrangler.jsonc` содержит один класс Durable Object с SQLite migration и статические файлы приглашения. Привязки создаются при первой публикации. Имя Worker по умолчанию `pulseparty`; при конфликте с вашим существующим Worker выберите другое имя до публикации. Приватные учётные данные не включаются в исходники.

`--dry-run` собирает и проверяет привязки без публикации. `deploy` действительно публикует HTTPS API в вашем аккаунте. Временное анонимное размещение Wrangler не используется: оно не подходит как постоянный сервис друзей.

После публикации передайте адрес из вывода команды:

```powershell
node scripts/set-relay.mjs <реальный-HTTPS-адрес>
npm run build
```

Конфигуратор проверяет версию `/v1/health`. Vite использует адрес в коде и манифесте `allowedUrls`; произвольный адрес из входящего приглашения не используется для подключения. При смене адреса пересоберите и обновите аддон у всех участников.

## Проверка перед приглашением друзей

1. `/v1/health` содержит `ok: true`, `protocol: 1` и актуальную версию `build` по публичному HTTPS-адресу.
2. Два компьютера с одинаковой сборкой аддона создают/присоединяются к комнате.
3. Смена трека, пауза и передача управления работают.
4. Отозванное приглашение и чужая сессия не дают входа/управления.
5. В кабинете Cloudflare выбран Free; фактическое потребление запросов укладывается в лимиты.

Локальная проверка в workerd и успешная публикация не доказывают воспроизведение на двух аккаунтах и доступность из региона каждого участника.

## Локальная разработка

```powershell
npm run dev:cloudflare
# В другом терминале:
npm run test:cloudflare
```

Это временный тестовый процесс на `127.0.0.1:8788`. После проверки его нужно остановить; для друзей localhost не используется. Для UI-теста запустите `npm run preview`, задайте `PULSEPARTY_TEST_RELAY_URL=http://127.0.0.1:8788` и выполните `npm run test:ui`.

Сервис хранит комнаты в памяти: перезапуск/вытеснение объекта завершает сессии, постоянная БД комнат не создаётся. Нет application access logs, аудио, токенов Яндекса/Discord, публичного списка комнат. Провайдер инфраструктуры обрабатывает сетевые метаданные.
