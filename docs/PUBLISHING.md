# Подготовка публикации PulseSync

Основание: [правила публикации PulseSync](https://pulsesync.dev/wiki/main/app/addons/publishing), редакция 30.10.2026, прочитаны 19.11.2026.

- Название: PulseParty.
- Автор: Kamilhik.
- Версия: 0.3.1.
- Репозиторий: https://github.com/Kamilhik/PulseParty-PulseSyns.
- Использование ИИ: **да, OpenAI Codex** — отметить и в форме каталога.
- Описание: закрытые комнаты совместного прослушивания Яндекс Музыки с передачей пульта, приглашениями по ссылке/коду и настройкой переключения очереди ведущего. Работает со стандартным PulseSync и общим HTTPS-сервисом.
- Список изменений: addon/CHANGELOG.md, включён в архив.
- Основа: официальный WebHost SDK и структура PulseSync-ExampleAddon.
- Аватарка `Assets/avatar-v1.png` включена в архив и указана в `image` и `libraryLogo`. Баннер не заявлен. При публикации в качестве превью используется эта же оригинальная аватарка.
- Сетевое разрешение ограничено https://pulseparty.pulseparty.workers.dev/v1. Передаваемые данные и фактические ограничения описаны в README аддона.

Релиз GitHub не означает автоматического появления в каталоге PulseSync. Первая публикация и обновления проходят отдельную модерацию. Нативные приглашения Discord и измеренная синхронность звука на двух компьютерах не заявляются как проверенные функции.

В каталог подаётся архив аддона, а не полный репозиторий и не историческая native-сборка. Для `.pext` используются ZIP-данные с metadata.json в корне, как в официальном экспорте PulseSync-client.
